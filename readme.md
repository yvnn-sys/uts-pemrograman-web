Rekap Nilai Mahasiswa
Proyek ini dibuat untuk tugas UTS Pemrograman Web. ini dibuat menggunakan PHP dan MySQL dengan tampilan AdminLTE.
Di dalam proyek ini, saya membuat fitur tambah data mahasiswa, upload foto, pencarian nama, filter predikat, sorting nilai akhir, dan pagination. Nilai huruf serta predikat juga ditentukan otomatis berdasarkan nilai akhir yang dimasukkan.
Proyek ini dibuat dan dijalankan menggunakan Laragon. File database juga disertakan agar bisa diimpor saat aplikasi ingin dijalankan kembali.
